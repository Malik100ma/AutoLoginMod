# AutoLogin (Fabric, Minecraft 1.21.11, client-side)

Когда вы заходите на сервер, мод автоматически отправляет `/login <пароль>`.

## Возможности
- Пароль задаётся в настройках (экран мода или `config/autologin.json`).
- Вкл/выкл мода в настройках.
- Настройки открываются по бинду (по умолчанию **Right Shift**, меняется в Управлении -> AutoLogin).
- Дополнительный бинд для быстрого вкл/выкл (по умолчанию не назначен).
- Задержка перед отправкой: поле `delayTicks` в `config/autologin.json` (20 = 1 сек.).
- Не срабатывает в одиночной игре.

## Сборка
Нужны JDK 21 и Gradle (или Gradle Wrapper):

    gradle wrapper      # один раз, если нет gradlew
    ./gradlew build

Готовый мод: `build/libs/autologin-1.0.0.jar` (не `-sources`). Положите в `mods/` вместе с Fabric API.

## Безопасность
Пароль хранится в `config/autologin.json` открытым текстом. Не делитесь этим файлом.
